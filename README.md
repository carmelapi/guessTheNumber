# Guess the Number 🎮

A browser-based number guessing game with two game modes.

🔗 **Live demo:** https://guesscarmelanumber.netlify.app

## How to play

**Guess the Number**
The computer generates 4 secret numbers (0-9, no repetitions).
- 🟢 Green = correct number, correct position
- 🟠 Orange = correct number, wrong position
You have 5 attempts. Good luck!

**Guess the Question**
The computer gives you an answer — you have to guess 
the right question. Tests creativity and knowledge!
